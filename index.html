UES Website Work Log

A plain-language record of the work done on universalenvironmentalservices.com.

Prepared by Manny Pachano for Juan Fritschy and Lisa Sandefur.

Last updated: August 4, 2026

What this page is. Each row below is a problem we found and what we did about it. It is written for people who do not work with websites.

Traffic and ranking figures are not on this page. Those are covered in the monthly reports.

1Problems solved

Most of these are normal for a site that ran for years without a technical check. None were caused by recent activity. Where a change was made to the live site, it was tested before and after.

The problemWhat we did about itWhen
The footer still read 2017 to 2022 Changed it to 2026. It now updates itself every year. August 3
The site loaded under four different web addresses, and search engines could not tell which one was correct Set one address as the correct one. The other three now send visitors and Google to it automatically. August 3 and 4
A full copy of the site was public at a second address That address now sends visitors and Google to the real site instead. August 4
The site's automatic task scheduler had stopped, so backups and updates were stuck Set it to run every five minutes. Scheduled jobs work again. August 4
Nothing was saved in visitors' browsers, so every repeat visit downloaded the whole site again Set images and design files to save in the browser. Repeat visits load faster. August 4
